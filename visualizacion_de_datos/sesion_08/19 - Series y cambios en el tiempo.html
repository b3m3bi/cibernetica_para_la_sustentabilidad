19 - Series de tiempo y cambios en el tiempo

Introducción

Para visualizar como cambia una variable en el tiempo se pueden usar las series de tiempo y los gráficos de dispersión conectados. Además se pueden crear animaciones que muestren cambios en el tiempo en las gráficas.

Objetivos

  • Crear gráficos de series de tiempo en ggplot
  • Crear gráficos de dispersión conectados
  • Identificar cómo crear animaciones en ggplot

Series de tiempo

Para hacer series de tiempo podemos usar geom_line(). Por ejemplo, hagamos un gráfico que muestre cómo ha cambiado la población de México en el tiempo:

datos_mex <- datos |> 
  filter(country == "Mexico")

ggplot(
  data = datos_mex,
  mapping = aes(x = year, y = population)
) + 
  geom_line() +
  labs(
    x = "Año",
    y = "Población"
  )

Grafico de dispersión conectado

Una forma de mostrar cambios en el tiempo para dos variables simultáneamente podemos usar gráficos de dispersión pero donde conectamos puntos en el tiempo. Por ejemplo, veamos cómo ha cambiado el producto interno bruto de México y las emisiones de CO2 en el tiempo. Para conectar los puntos que seguidos usamos geom_path() y además usamos geom_text_repel() (del paquete ggrepel) para poner las leyendas de los años evitando que estas se sobrelapen con los puntos:

#install.packages("ggrepel")
library(ggrepel)

# Quitamos todas las filas que tienen NA
datos_mex <-datos_mex |> drop_na()

ggplot(
  data = datos_mex,
  mapping = aes(
    x = average_fertilizer_per_ha,
    y = annual_co2_emissions_per_capita,
    label = year
  )
) + 
  geom_point() +
  geom_path() +
  geom_text_repel(size = 3) + 
  labs(
    x = "Uso promedio de fertilizante por ha",
    y = "Emsiones anuales de CO2 per capita"
  )

  • ¿Qué ha pasado con el uso de fertilizando y con las emisiones de CO2 per cápita a lo largo del tiempo?

Animaciones

Otra forma de mostrar cambios en el tiempo es usando animaciones. Para eso podemos usar los paquetes gganimate y gifski. Por ejemplo, veamos cómo ha cambiado la esperanza de vida y el producto interno bruto per cápita en el tiempo:

# install.packages("gganimate")
# install.packages("gifski")
library(gganimate)
library(gifski)

p <- ggplot(
  data = datos,
  mapping = aes(x = gdp_per_capita, y = life_expectancy, color = continent, size = population)
) + 
  geom_point() +
  labs(
    x = "Producto interno burto per cápita",
    y = "Esperanza de vida",
    color = "Continente",
    title = "Año: {frame_time}"
  ) + 
  scale_x_continuous(transform = "log10", labels = scales::label_dollar()) + 
  scale_y_continuous(transform = "log10", labels = scales::label_number()) + 
  transition_time(year) +
  ease_aes("linear")
